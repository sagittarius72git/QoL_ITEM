# QoL アイテム (QoL Item)

便利なアイテムをまとめたMODです。

- **縄梯子** … 段差の縁から垂らして降りたり、下から掛けて登ったりできる
- **自作ウォーターサーバー** … 液体グリッドの水を「自動飲料」で飲めるようにする
- **間に合せの包帯・間に合せの消毒** … 仲間が何度でも使える手当て道具
- **アンクルウォーマー・ウールアンクルウォーマー** … 蹄や鉤爪など、変異した足でも着けられる足首の防寒具
- **変異体ペストマスク・変異体ハーフペストマスク** … 口が変異していても着けられるガスマスク
- **小型段ボール・大型段ボールのレシピ** … 本編の段ボール箱を作れるようにする

**Lua対応ビルドが必要です**（`lua_api_version: 2`）。

---

## 縄梯子
製作メニュー「その他」→「道具」

使う（`a`）と3通りから選べます。

- **縁から垂らす** … 隣の段差の縁を選ぶと、その真下に**最大3階分**垂らします（屋根や崖から降りるとき）。
- **ここに設置する** … 同じ高さの隣のマスに掛けます（下から1階分登るとき。鉤縄と同じ）。そのマスに地面がなければ、上の縁に投げて引っ掛け、宙づりで掛かります。
- **向こう側へ渡す** … 同じ高さで離れた地面へ投げ渡し、橋にします（下を参照）。

上の階で縁を調べると「引き上げる」、縄梯子のいちばん上のマスを調べると「取り外す」で回収できます。
- 使って「向こう側へ渡す」を選び、方向を決めると、同じ高さで**3マス先まで**の向こう側の地面へ投げ渡して引っ掛けます。間の空中に縄梯子が渡り、橋のように渡れます。
- **MODを外す前に、渡した縄梯子は回収してください。**

## 自作ウォーターサーバー
製作メニュー「その他」→「容器」

1. 使って「ウォーターサーバーを設置する」を選び、**液体グリッドのある建物の中**の何もない床に置く
2. 置いたマスを「自動飲料」区域にする

中に1Lまで水が入り、空になると1分以内に、置いた場所（マップの同じ区画）の液体グリッドから**きれいな水**が補充されます（汚れた水は補充しません）。流し台・浴槽・シャワー・タンクの隣に置いたときは、その設備のグリッドから汲みます。
近く（同じ階の60マス以内）で長い作業中にのどが渇くと、自動で飲みます。調べると水の量の確認と回収ができます。

- 本体の自動飲料は、飲み物がないと30分は探し直しません。
- 手動では飲めません（自動飲料専用）。
- 液体グリッドにつながっていない区画に置くと、水は入りません。

## 間に合せの包帯・間に合せの消毒

どちらも製作メニュー「その他」→「医療」（応急手当1）。

| | 材料 | 時間 |
|---|---|---|
| 間に合せの包帯 | ぼろ布×6（血まみれのぼろ布でも可）、短いひも×2かダクトテープ×10 | 10分 |
| 間に合せの消毒 | 小型・中型ブリキ缶（開封済みでも可）かガラス瓶×1、ぼろ布×1（血まみれでも可）、消毒薬×1回分 | 5分 |

仲間の持ち物に入れておくと、仲間がけがをしたときに自分で手当てに使います。**何回使ってもなくなりません。**

| | 間に合せの包帯 | 間に合せの消毒 | （参考）急造包帯 |
|---|---|---|---|
| 包帯の強さ | 2 | ― | 2 |
| 止血の成功率 | 75% | ― | 75% |
| 消毒（かみ傷の治療） | ― | 強さ1・30% | ― |
| 時間 | 3秒 | 2秒 | 3秒 |

- **プレイヤーは使えません**（「装填量は1以上必要だ」と出ます）。
- 本物の包帯なども持たせていると、どちらを使うかは本体のAI任せです。
- 仲間がプレイヤーや他の仲間の手当てに使うこともあります（その場合も減りません）。

## アンクルウォーマー・ウールアンクルウォーマー

製作メニュー「防具」→「足」（裁縫）。

| | 材料 | 時間 |
|---|---|---|
| アンクルウォーマー | 靴下と同じ（布切れ×2ほか） | 10分 |
| ウールアンクルウォーマー | ウールの靴下と同じ（毛糸ほか、裁縫1） | 1時間 |
| （どちらも）手持ちの靴下から | 靴下×1 または ウールの靴下×1、切断1 | 5分 |

暖かさなどの性能は元の靴下・ウールの靴下と同じです。蹄や鉤爪のある足、ウサギのような足、触手の脚、巨体化の変異があっても着けられます。

## 変異体ペストマスク・変異体ハーフペストマスク

製作メニュー「防具」→「頭」（裁縫）。

| | 材料 | 時間 |
|---|---|---|
| 変異体ペストマスク | ガスマスクと同じ材料＋革×4（またはプラスチック片×4）、裁縫3・製作1、レンチ | 30分 |
| （同）手持ちのガスマスクから | ガスマスク×1、革×4（またはプラスチック片×4）、裁縫2 | 20分 |
| 変異体ハーフペストマスク | 防塵マスク×3、ホース×1、炭×20、革×3（またはプラスチック片×3）、裁縫3・製作1、レンチ | 20分 |

- フィルターなどの性能はガスマスクと同じです（使う前に準備が必要）。そのかわり動作制限はガスマスクより高めです（30→35）。
- ハーフは口だけを覆います（目は守りません）。
- 鼻面・くちばし・大顎・口吻・サーベルのような牙などの変異や、巨体化の変異があっても着けられます。

## 小型段ボール・大型段ボール

本編のアイテムを、製作メニュー「その他」→「容器」（製作1、切断1）で作れるようにします。本編の段ボール箱のレシピと同じ作り方です。

| | 材料 | 時間 |
|---|---|---|
| 小型段ボール | 段ボール×18、ダクトテープ×20 | 3分 |
| 大型段ボール | 段ボール×130、ダクトテープ×150 | 15分 |

## 設定

`main.lua` で変えられます。

- 縄梯子：`mod.cfg.max_levels`（縁から垂らせる最大の階数）、`mod.cfg.move_cost`（1階分を垂らすのにかかる時間）、`mod.cfg.allow_hanging`（宙づりにできるか）、`mod.cfg.bridge_max_dist`（向こう側へ渡せる距離）
- 自作ウォーターサーバー：`CFG.need_fixture`（`true` で以前のように流し台などの隣だけに置ける）、`CFG.fixtures`（流し台などの設備）、`CFG.refill_charges`（1回の補充量）
