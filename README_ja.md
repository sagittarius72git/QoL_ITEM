# QoL アイテム (QoL Item)

便利なアイテムをまとめたMODです。

- **縄梯子** … 段差の縁から垂らして降りたり、下から掛けて登ったりできる
- **自作ウォーターサーバー** … 液体グリッドの水を「自動飲料」で飲めるようにする
- **間に合せの包帯・間に合せの消毒** … 仲間が何度でも使える手当て道具
- **即席レーザータレット** … 広げて置く自動タレット。電力グリッドにつなげる

**Lua対応ビルドが必要です**（`lua_api_version: 2`）。

---

## 縄梯子

製作メニュー「その他」→「道具」（製作2、30分、切断1）。
材料：ロープ類×2本分（長いロープ・即席ロープ・ツタ・プラスチックロープ。短いものなら×10）、2x4×8

使う（`a`）と3通りから選べます。

- **縁から垂らす** … 隣の段差の縁を選ぶと、その真下に**最大3階分**垂らします（屋根や崖から降りるとき）。
- **ここに設置する** … 同じ高さの隣のマスに掛けます（下から1階分登るとき。鉤縄と同じ）。そのマスに地面がなければ、上の縁に投げて引っ掛け、宙づりで掛かります。
- **向こう側へ渡す** … 同じ高さで離れた地面へ投げ渡し、橋にします（下を参照）。

登り降りと回収は本体の鉤縄と同じです。上の階で縁を調べると「引き上げる」、縄梯子のいちばん上のマスを調べると「取り外す」で回収できます。
深い水・壁・家具・人がいる場所には垂らせません（途中の階にあれば、その手前まで垂らします）。

### 2階分以上・宙づり

- 2階分以上垂らしたときは、`>` と `<` で縄梯子を伝って1階ずつ上り下りします。いちばん上からは、今までどおり縁の上へ戻れます。
- 地面より上の区間は**宙づり**です。どの階でも縄梯子につかまったまま、隣の窓などから建物に入れます（屋上から上の階へ忍び込むときなど）。3階分で地面に届かなければ、いちばん下も宙づりのまま止まります。
- 縄梯子のマスから横の空中へ踏み出すと落ちます。
- 回収するといちばん上から全部外れます（縄梯子1つに戻ります）。途中を壊されると、そこから下が落ちます。
- **MODを外す前に、2階分以上・宙づりの縄梯子は回収してください。**
### 向こう側へ渡す

- 使って「向こう側へ渡す」を選び、方向を決めると、同じ高さで**3マス先まで**の向こう側の地面へ投げ渡して引っ掛けます。間の空中に縄梯子が渡り、橋のように渡れます。
- 間のマスがすべて何もない空中で、その先に地面（壁や深い水ではない）があるときだけ渡せます。
- 渡した縄梯子を調べると「取り外す」で回収できます（足元に戻ります）。どこか1マスでも壊されると、全部外れて落ちます。
- **MODを外す前に、渡した縄梯子は回収してください。**

## 自作ウォーターサーバー

製作メニュー「その他」→「容器」（製作1、20分、切断1）。
材料：ガロン容器×1（またはペットボトル×4／プラスチック水筒×1）、ゴムホースか革製ホース×1、板材×2か重い棒×4、ダクトテープ×20か長いひも×1

1. 使って「ウォーターサーバーを設置する」を選び、**液体グリッドのある建物の中**の何もない床に置く（流し台などの隣でなくても大丈夫です）
2. 置いたマスを「自動飲料」区域にする

中に1Lまで水が入り、空になると1分以内に、置いた場所（マップの同じ区画）の液体グリッドから**きれいな水**が補充されます（汚れた水は補充しません）。流し台・浴槽・シャワー・タンクの隣に置いたときは、その設備のグリッドから汲みます。
近く（同じ階の60マス以内）で長い作業中にのどが渇くと、自動で飲みます。調べると水の量の確認と「片付ける」ができます。

- 本体の自動飲料は、飲み物がないと30分は探し直しません。
- 寒いと中の水が凍って飲めません。屋内に置くのがおすすめです。
- 手動では飲めません（自動飲料専用）。
- 液体グリッドにつながっていない区画に置くと、水は入りません。調べると「液体グリッドに、きれいな水がない」と出ます。

## 間に合せの包帯・間に合せの消毒

どちらも製作メニュー「その他」→「医療」（応急手当1）。

| | 材料 | 時間 |
|---|---|---|
| 間に合せの包帯 | ぼろ布×6（血まみれのぼろ布でも可）、短いひも×2かダクトテープ×10 | 10分 |
| 間に合せの消毒 | 小型・中型ブリキ缶（開封済みでも可）かガラス瓶×1、ぼろ布×1（血まみれでも可）、消毒薬×1回分 | 5分 |

仲間の持ち物に入れておくと、仲間がけがをしたときに自分で手当てに使います。**何回使ってもなくなりません。**

| | 間に合せの包帯 | 間に合せの消毒 | （参考）急造包帯 |
|---|---|---|---|
| 包帯の強さ | 2 | ― | 2 |
| 止血の成功率 | 75% | ― | 75% |
| 消毒（かみ傷の治療） | ― | 強さ1・30% | ― |
| 時間 | 3秒 | 2秒 | 3秒 |

- **プレイヤーは使えません**（「装填量は1以上必要だ」と出ます）。
- 本物の包帯なども持たせていると、どちらを使うかは本体のAI任せです。
- 仲間がプレイヤーや他の仲間の手当てに使うこともあります（その場合も減りません）。
- 以前の「間に合せの治療」は、そのまま**間に合せの包帯**になります。消毒も持たせたいときは新しく作ってください。

## 即席レーザータレット

製作メニュー「武器」→「遠距離」（電子工学5、2時間）。粗悪なレーザーライフルと同じく、自動で覚えるか電子工学の本で覚えます。
材料：粗悪なレーザーライフル×1、中型蓄電池×1、パイプ×7、小型モーター×2、ばね×1、カメラ類×1、電子部品くず×5、ケーブル×30、はんだ付け（30）。道具：精密ドライバー、レンチ、金属のこ

1. 使う（`a`）と、足元に広げて設置します（1マスの車両になります）。
2. タレットのマスで車両を操作し、タレットの射撃モードを**自動**にします。
3. 近づいた敵を、電力を使って自動で撃ちます。

- 持ち運ぶときは、車両メニューから**折りたたむ**とアイテムに戻ります（電池の残りや傷みはそのまま）。
- 内蔵の中型蓄電池で動きます。**初めて広げたときは空**なので、先に充電してください。
- 電力グリッドで動かすには、グリッドのある建物に「ジャンパーケーブル接続口」を建てて（建設メニュー「作業場」）、タレットとジャンパーケーブルでつなぎます。たたむ前にケーブルを外してください。
- 照準装置は外せますが、付け直せません（ほかの車両にも付けられません）。外すと自動射撃できなくなります。

## 設定

`main.lua` で変えられます。

- 縄梯子：`mod.cfg.max_levels`（縁から垂らせる最大の階数）、`mod.cfg.move_cost`（1階分を垂らすのにかかる時間）、`mod.cfg.allow_hanging`（宙づりにできるか）、`mod.cfg.bridge_max_dist`（向こう側へ渡せる距離）
- 自作ウォーターサーバー：`CFG.need_fixture`（`true` で以前のように流し台などの隣だけに置ける）、`CFG.fixtures`（流し台などの設備）、`CFG.refill_charges`（1回の補充量）
