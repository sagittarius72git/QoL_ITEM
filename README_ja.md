# QoL アイテム (QoL Item)

便利なアイテムをまとめたMODです。Lua対応ビルドが必要です（`lua_api_version: 2`）。

## 縄梯子
製作：その他 → 道具。使う（`a`）と次から選べます。
- 縁から垂らす：隣の縁の真下へ最大3階分垂らす。
- ここに設置する：隣のマスに掛けて1階分登る。地面がなければ宙づりになる。
- 向こう側へ渡す：同じ高さで3マス先までの地面へ渡し、橋にする。

縁を調べて「引き上げる」、いちばん上のマスを調べて「取り外す」で回収します。渡した縄梯子はMODを外す前に回収してください。

## 自作ウォーターサーバー
製作：その他 → 容器。液体グリッドのある建物の床に設置し、そのマスを「自動飲料」区域にします。
- 液体グリッドからきれいな水を1Lまで自動で補充する（汚れた水は補充しない）。
- 近く（同じ階の60マス以内）で作業中にのどが渇くと自動で飲む。手動では飲めない。

## 間に合せの包帯・間に合せの消毒
製作：その他 → 医療（応急手当1）。仲間に持たせると、仲間が手当てに使います。何回使ってもなくならず、プレイヤーは使えません。
- 包帯：急造包帯と同じ性能（強さ2、止血75%）。
- 消毒：かみ傷の消毒（強さ1、30%）。

## アンクルウォーマー・ウールアンクルウォーマー
製作：防具 → 足。靴下・ウールの靴下と同じ性能で、蹄・鉤爪・触手の脚・巨体化などの変異があっても着けられます。手持ちの靴下からも作れます。

## 変異体ペストマスク・変異体ハーフペストマスク
製作：防具 → 頭。ガスマスクと同じ性能（動作制限は35）で、鼻面・くちばし・大顎などの口の変異や巨体化があっても着けられます。ハーフは口だけを覆います。通常版は手持ちのガスマスクからも作れます。

## 小型段ボール・大型段ボール
本編の段ボール箱を、製作：その他 → 容器 で作れるようにします。

## 設定
`main.lua` の `mod.cfg`（縄梯子）と `CFG`（ウォーターサーバー）で変えられます。
